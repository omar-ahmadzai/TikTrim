# TikTrim

A simple tool to remove the ending TikTok “creator card” and its sound from downloaded videos.

## Why this exists
When you download TikTok videos, the last few seconds show the creator’s username, link, and play a distinctive sound. Many of us embed TikTok clips in our own projects and don’t want that extra end-card.

## Features
- Command-line interface (Python)
- Auto-detect (placeholder) or specify how many seconds to strip
- Lightweight dependency on MoviePy / FFmpeg
